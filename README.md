# Java Customer Relationship Management (CRM) System

This is a simple yet enhanced **Customer Relationship Management (CRM)** system built in Java.  
It helps manage customers, record interactions, generate reports, and export data to a text file. Perfect for learning **OOP**, **file handling**, and **basic data structures** in Java.

## Features 🚀

✅ Add, Update, Delete, and List Customers  
✅ Record and view customer interactions (calls, meetings, emails, etc.)  
✅ Customer search by name, email, or phone  
✅ Auto-generated customer IDs  
✅ Activity reports: customer-wise interaction count  
✅ Export full data to a text file (`CRM_Report.txt`)  
✅ Simple, menu-driven console application  
✅ Clean, modular code (separated by classes)  
✅ Sorting customers alphabetically  
✅ View full interaction history per customer
